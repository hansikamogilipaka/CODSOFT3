# AI Image Caption Generator

An AI-powered desktop application that automatically generates captions for uploaded images using Deep Learning and Computer Vision techniques.

## Features

- Upload and preview images
- AI-generated captions
- Modern dark-themed GUI
- Real-time caption generation
- User-friendly interface
- Splash screen animation

## Technologies Used

- Python
- Tkinter
- PyTorch
- Hugging Face Transformers
- Pillow
- BLIP Image Captioning Model

## Installation

Install required libraries:

pip install torch transformers pillow sentencepiece

## Run the Project

python image_caption_ai.py

## Project Structure

AI-Image-Caption-Generator/
│

## How It Works

1. Upload an image
2. AI processes the image
3. BLIP model generates a caption
4. Caption appears instantly in GUI

## Output

The application automatically predicts meaningful captions for uploaded images using Artificial Intelligence.
